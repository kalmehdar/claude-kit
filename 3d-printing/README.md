# 3D printing

This moved to its own repo: [claude-3d-printing](https://github.com/kalmehdar/claude-3d-printing). It has the tools (one STL per colour from OpenSCAD, a mesh check, the Print Bench preview page), three example designs, and the 3D skills and agents.

The 3D skills and agents also stay in this kit (`skills/`, `agents/3d/`), so copying the kit still installs them.
